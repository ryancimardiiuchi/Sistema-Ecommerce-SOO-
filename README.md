# 🛒 Sistema E-commerce — SOO

## 📌 Sobre o projeto

Sistema de e-commerce desenvolvido em **Java**, utilizando o NetBeans, como projeto de estudo de **Sistemas Orientados a Objetos (SOO)**.

O projeto foi estruturado com classes, herança e relacionamentos entre entidades, representando um sistema de comércio eletrônico com diferentes tipos de usuários, produtos, pedidos, pagamentos e avaliações.

## 🧩 Estrutura do sistema

### 👤 Usuários — Classe mãe

A classe `Usuario` representa a estrutura base dos usuários do sistema.

Classes filhas:
- `Vendedor`
- `Cliente`
- `Administrador`

### 📦 Produtos — Classe mãe

A classe `Produto` representa a estrutura base dos produtos disponíveis no e-commerce.

Classes filhas:
- `Roupa`
- `Livro`
- `Eletronicos`

### 🛍️ Outras classes

- `Pedido` — representação dos pedidos realizados no sistema.
- `Pagamento` — representação dos pagamentos associados aos pedidos.
- `Avaliacao` — representação das avaliações dos produtos ou experiências de compra.

## 🏗️ Conceitos de orientação a objetos

- **Herança:** especialização das classes `Usuario` e `Produto` por meio de classes filhas.
- **Abstração:** representação dos principais elementos de um sistema de e-commerce.
- **Encapsulamento:** organização dos dados e comportamentos nas classes.
- **Relacionamentos entre classes:** representação das interações entre usuários, produtos, pedidos, pagamentos e avaliações.
